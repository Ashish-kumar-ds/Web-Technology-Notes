# Web Technology Study Hub

A responsive, unit-wise Web Technology notes website for CS35302.

## Files
- `index.html` — homepage and notes layout
- `style.css` — responsive styling and light/dark themes
- `script.js` — navigation and unit rendering
- `data.js` — unit-wise explanations and revision notes

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select `main` and `/ (root)`, then Save.
4. Wait for GitHub Pages to publish the site.

The site uses plain HTML, CSS and JavaScript; no build tools are required.
